# 用 AI Agent 构建 Marsquakes

你不需要写代码。你用大白话描述想要什么，**AI 编程助手（Agent）**——
一个可以聊天、同时也能读取和修改你电脑上文件的程序——会替你写代码、敲命令，
然后把结果拿给你看。

这条线会一字一句地告诉你该说什么，从一台空电脑，走到一个能拿给别人看的成品应用。

## 两个会反复出现的词

| 词 | 在这里的含义 |
| -- | ------------ |
| **Agent（智能体）** | 你与之对话的程序。它替你写代码、运行工具，然后向你汇报。中文页面使用 DeepSeek Harness；英文页面使用 OpenAI Codex CLI——说法略有不同，工作方式完全一样 |
| **Skill（技能）** | 一小包说明书，你只需交给 Agent 一次，它就会按正确的顺序安装正确的程序，而不是靠猜 |

第一个阶段会把它们都装好。

## 每一页怎么用

- **这样说**——一段可以直接复制粘贴的大白话。它要求的永远是一个*你能看见的结果*，
  而不是某个技术动作。
- **你应该看到：**——一个要打开的网址、一个弹出来的窗口、一份改动文件的清单。
  你靠看来检查成果，不需要读代码。
- 如果看到的和描述不符，页面会给你下一句该说的话。

Agent 打印出来的文字你基本不用懂。记住两个习惯：动手前先要方案，一次只做一个功能。

## 整个旅程

| 阶段 | 页面 | 完成后你拥有什么 |
| ---- | ---- | ---------------- |
| 1 —— 环境准备 | [安装 Agent](./ai-setup-agent.md)、[安装 Skill](./ai-setup.md)、[配合 AI Agent 使用](./ai-agents.md) | 一个能对话、且懂这个项目环境准备的 Agent |
| 2 —— 开始一个项目 | [开始一个项目](./ai-start.md) | 一个创建好的项目，且只装了它真正需要的工具链 |
| 3 —— 应用 | 下面每个端各有一组页面 | 一个跑起来的应用、里面的新功能，以及一个能交给别人的安装包 |

第 2 阶段只装你勾选的端所隐含的工具链——只做桌面端的机器永远不会装 Java 工具链。

在**应用**之下，每个端都展开成同样的三页：

| 页面 | 产出什么 |
| ---- | -------- |
| 创建项目 | 空空的、能跑起来的起点——一个登录页、一个应用窗口，或手机上的一个应用 |
| 创建功能 | 里面的一个真实功能，比如管理文章或商品 |
| 部署 / 打包 | 一个能交给别人的成品文件——安装包、发布版 APK，或整套跑在 Docker 里的系统 |

| 平台 | 如果你想要……就选它 |
| ---- | ------------------ |
| [后台管理系统](./ai-admin-project.md) | 一个需要登录、用来管理东西的网站——商品、订单、用户、文章 |
| [桌面应用](./ai-desktop-project.md) | 一个有独立窗口、装在电脑上的真正程序 |
| [Android 应用](./ai-android-project.md) | 一个装在 Android 手机上的应用 |

不知道选哪个？[开始一个项目](./ai-start.md)开头正是这个问题。
