# 构建桌面应用：打包

等[创建功能](./ai-desktop-module.md)做出的东西在开发窗口里跑通之后，只需要说一句话。最后你会得到一个安装包文件，发给别人，双击就能装。

## 第 1 步 —— 构建安装包

> **提示词**
>
> 把桌面应用构建成正式的发布版本，然后告诉我安装包文件到底在哪。

**你应该看到：** 一个真实的文件路径，后缀是你电脑对应的那种安装包——Windows 上是
`.msi` 或 `.exe`，macOS 上是 `.dmg`，Linux 上是 `.deb` 或 `.AppImage`。一定要问路径：
"构建成功了"这句话你没法验证，一个你能打开看的文件才行。

那个文件就是你发给别人的东西。别人不需要装你装过的任何工具。

:::note 这一步没有捷径
跟后台管理系统不一样，这个应用没法在 Docker 里打包——它必须在一台真实的电脑上构建，
而且要和你要发给的那些人用同一类电脑。如果 Agent 开始找 Docker 的做法，就说：
"桌面应用没有 Docker 这条路，直接构建。"
:::

## 卡住了怎么办

你不需要自己诊断。找到你看到的现象，把对应那句话说出去：

| 你看到什么 | 这样说 |
| ---------- | ------ |
| 构建每次报在不一样的样式文件上 | "去看最外层 AGENTS.md 里要求的那个构建配置——不要改锁定的版本" |
| Agent 很久没说话了 | "你是不是在等一个永远不会结束的东西？换一种不会耽误你跟我说话的方式启动，起来了告诉我" |
| Agent 开始找 Docker 的构建办法 | "桌面应用没有 Docker 这条路，直接构建" |
