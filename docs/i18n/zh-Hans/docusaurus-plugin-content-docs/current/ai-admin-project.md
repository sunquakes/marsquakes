# 构建后台管理系统：创建项目

三句提示词，按顺序说。每一句都以一个你能看见的结果收尾——你不需要读代码。
这一页假设你的电脑已经准备好了——见[开始一个项目](./ai-start.md)。

一个后台管理系统是一对**配套的**部分：你看到的网页，和背后存数据的后端。
分开来要，只会得到两个互不相认的项目，所以每句提示词都把两半当作一个整体。

## 第 1 步 —— 创建项目

> **提示词**
>
> 在当前文件夹下创建一个叫 `admin-platform` 的项目，只做网页版管理系统——
> 不要手机端、不要桌面端、不要门户网站。用 Marsquakes 那个工具来创建。

**你应该看到：** 确认创建了正好两个部分。

```
✅ Selected 2 modules:
   - Web Admin
   - API Service
```

然后问："你实际创建了哪几个目录？"答案应该只提到那两个。多出来的就是建错了——
说"删掉重新来，只要那两个"。（其他任何组合——哪怕是[桌面应用](./ai-desktop-project.md)
——都会让工具停下来问；后端加管理后台是默认值。）

## 第 2 步 —— 安装项目需要的东西

:::note 建项目这一步什么都不会安装
第 1 步只负责拷贝文件和初始化 Git——它最后的提示里就写着下一步该执行
`mars init`。在此之前依赖没装、Java 和 Maven 没有、`.env` 文件也没有，两个半端
哪个都起不来；两步分开也是为了断网时照样能建项目。别因为第 1 步"看着完成了"
就跳过这一步。
:::

> **提示词**
>
> 把这个项目需要的东西都装上，该做的设置按惯例配好。我在国内网络，下载源用适合
> 这个网络的。第一次启动任何东西之前，先把数据仓库的密码填好。

说清楚你在哪很重要：下载源选错了，两分钟的事会变成二十分钟的慢爬。

**你应该看到：** 项目最外层出现一个设置文件，密码已经填好；安装全程没有报错。
Java 和 Maven 若原本没有，也是在这一步装上的——在[配环境](./ai-start.md)
时是故意跳过的，因为第 1 步把项目建出来之前，谁也不知道你要做后端。

:::caution "Java 明明是好的，却说 JAVA_HOME 没设置"
不是坏了——那个终端窗口在 Java 装完之前就打开了，拿的是过期信息。你说：
"重新开一个终端窗口再检测一遍，不要重装。"重装 Java 一点用都没有。
:::

:::note 安装慢得像爬不是失败
几乎都是从地球另一边在下载。你说："换成适合我所在地区的下载源，重新试一次。"
不要干等着。
:::

## 第 3 步 —— 把它跑起来并打开

Agent 会自动采用最方便的**标准方式**，不需要你做任何选择：数据存放在你电脑上的
"盒子"里运行（Docker 本就是环境准备那一页留给你的、已经就绪的电脑的一部分），
系统本身跑在你的电脑上，修改能立刻生效。你自始至终只需要看网页。

> **提示词**
>
> 按标准方式把整个系统启动起来，告诉我该在浏览器里打开哪个网址。让所有东西在我们工作
> 期间一直跑着，准备好了就告诉我。

**你应该看到：** Agent 说出一个以 `http://localhost` 开头的网址，浏览器里出现登录
页面。你只需要打开这一个页面——数据仓库和后台干活的服务都会默默一起启动、待在
后台，Agent 仍能跟你说话；第一次启动更慢，因为空的数据仓库要先填好。

:::note 页面打开了，但其实还没完全准备好
第一次运行时登录失败、或每个页面都报错，通常是服务还没启动完。等一下再刷新；
如果一直这样，就说："有东西没启动完——你检查一下，准备好了告诉我。"
:::

:::note 网页找不到数据时
Agent 偶尔会把整个系统都放进盒子里，两半便没法用平时的名字互相找到。如果网页
提示连不上数据，就说："用标准的本地方式——数据仓库放在它的盒子里，系统正常
跑在我的电脑上。"
:::

登录页能正常打开，空架子就搭好了。用 `admin` / `123456` 登录。下一步：
[创建功能](./ai-admin-module.md)。

## 卡住了怎么办

你不需要诊断任何东西。找到你的症状，说那句话：

| 你看到什么 | 这样说 |
| ---------- | ------ |
| 安装卡住不动了 | "换成适合我所在地区的下载源，重新试一次" |
| 数据库报"拒绝访问" | "密码是在数据库第一次创建之后才改的。把数据卷删掉，重新建一个" |
| 管理后台能打开，但点什么都报错 | "有东西没启动完——按标准方式把整个系统启动起来，页面能用了告诉我" |
| 报了一个"no package named api" | "后台干活的服务要用它自己的方式启动——它不归网页的工具管" |
| 网页找不到数据 | "用标准的本地方式——数据仓库放在它的盒子里，系统正常跑在我的电脑上" |
| Agent 很久没动静了 | "你在等一个永远不会结束的东西吗？换一种不会耽误你跟我说话的方式启动，起来了告诉我" |
