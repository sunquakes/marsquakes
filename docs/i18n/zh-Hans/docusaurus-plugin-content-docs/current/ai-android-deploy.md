# 构建 Android 应用：打包

等[创建功能](./ai-android-module.md)做出的东西在你的设备上跑通之后，只需要说一句话。
最后你会得到一个 APK 文件，可以装到手机上，也可以发给别人。

## 第 1 步 —— 构建发布版 APK

> **提示词**
>
> 把 Android 应用构建成正式的发布版本，然后告诉我 APK 文件到底在哪。

**你应该看到：** 一个真实的文件路径，以 `.apk` 结尾。一定要问路径："构建成功了"
你没法验证，一个你能打开看的文件才行。

那个文件就是你发给别人的东西，别人不需要装你装过的任何工具。

:::note APK 能用，但还不能上架 Google Play
这里构建的发布版 APK 用的是调试签名密钥，可以测试和侧载安装，但不能上传到 Google Play
Store。等你准备好正式发布时，就说："给发布构建配一个正式的签名密钥，然后重新签名 APK。"
:::

## 卡住了怎么办

你不需要自己诊断。找到你看到的现象，把对应那句话说出去：

| 你看到什么 | 这样说 |
| ---------- | ------ |
| 构建出现编译错误 | "读 `apps/android/AGENTS.md`，按它指出的错误修复，然后重新构建" |
| Gradle 找不到 JDK 或 Android SDK | "为本项目重新跑一次 `mars init`，然后开一个新终端再试" |
| 发布版 APK 上不了应用商店 | "配置一个正式的发布签名密钥，用它给 APK 签名" |
| Agent 很久没说话了 | "你是不是在等一个永远不会结束的东西？换一种不会耽误你跟我说话的方式启动，起来了告诉我" |
