Always write commit messages in English only. Never use Chinese.

Format: `<type>(<scope>): <subject>`, optional body after a blank line.

- type: feat | fix | docs | style | refactor | test | chore | perf | ci | revert
- subject: imperative mood, capitalized, under 50 chars, no trailing period
- body: optional English bullet points, wrapped at 72 chars
- One commit covers one logical change
